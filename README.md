# 🚚 ChainShield AI

An AI-powered Supply Chain Risk Prediction and Shipment Intelligence Platform that helps logistics teams predict shipment risks, monitor deliveries in real time, and analyze operational performance using Machine Learning.

---

## 📖 Overview

ChainShield AI is a full-stack web application that combines Machine Learning with interactive analytics to improve supply chain visibility and decision-making.

The platform enables users to:

- Predict shipment risk using an AI model
- Monitor shipments in real time
- Analyze logistics performance
- Generate business reports
- Explore AI model insights
- Manage shipment records through an intuitive dashboard

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone https://github.com/SnehaSuryavanshi/ChainShield-AI.git
```

```
cd ChainShield-AI
```

---

# Backend Setup

```
cd backend
```

Create virtual environment

```
python -m venv venv
```

Activate it

Windows

```
venv\Scripts\activate
```

Install dependencies

```
pip install -r requirements.txt
```

Run the backend

```
python app.py
```

Backend will start on

```
http://127.0.0.1:8000
```

---

# Frontend Setup

```
cd frontend
```

Install dependencies

```
npm install
```

Run development server

```
npm run dev
```

Frontend will start on

```
http://localhost:5173
```
